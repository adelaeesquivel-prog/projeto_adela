LÉO BARBAS — PÁGINAS HOME E SERVIÇOS

Arquivos incluídos:
- home.html: página inicial.
- servicos.html: catálogo de serviços.
- servicos.js: lê os serviços do localStorage usado pelo seu sistema atual.
- site-pages.css: estilos complementares.

COMO INSTALAR
1. Extraia os arquivos na mesma pasta onde já estão index.html, style.css e script.js.
2. Não apague nem substitua seus arquivos atuais.
3. Abra home.html no navegador (ou pelo Live Server do VS Code).
4. Use os links do menu para navegar entre Home, Serviços e Agendamento.

IMPORTANTE — MENU NA PÁGINA DE AGENDAMENTO
Para que o menu também apareça na sua página atual (index.html), dentro do <header>, depois do parágrafo "Seu estilo começa aqui!", acrescente:

<nav class="site-nav" aria-label="Navegação principal">
  <a href="home.html">Home</a>
  <a href="servicos.html">Serviços</a>
  <a class="active" href="index.html">Agendamento</a>
</nav>

No <head> do index.html, depois do link do style.css, acrescente:
<link rel="stylesheet" href="site-pages.css">

OBSERVAÇÃO
A página Serviços consulta a chave "leo_servicos" do localStorage, que é a mesma usada no seu script.js. Assim, quando o administrador cadastrar ou excluir um serviço no painel, a página Serviços mostrará a lista atualizada nesse mesmo navegador.
